# Operational comparison evidence

See the [interpretation and criteria](../../../docs/tooling-operations-comparison.md).
The probe deliberately changes and removes **disposable installations**. Never
point it at an accepted worktree cache, a normal host prefix or a shared Nix store.
The accepted M1–M4 candidate inputs are not changed.

## Recorded execution

- [Summary](summary.json): before/after SHA-256 assertions and bounded outcomes.
- [mise with the accepted metadata-supplied checksums](mise.json).
- [mise with an independently checked archive lock](mise-revalidated.json).
- [aqua](aqua.json).
- [Managerless control](baseline.json).
- [Nix](nix.json).
- [Online preparation and runtime identities](preparation.json).
- [Fixture inputs](fixtures/): metadata only; no downloaded binaries or cache payloads.

The full temporary execution workspace was `/tmp/score-operations-20261101`.
Ubuntu commands run non-root under `--network none` with only task-owned writable
state. The Nix target container also has `--network none`, but is root within its
own fresh store. The producer store is separate and is never corrupted. The
25-second limit on aqua recovery is an experimental bound, not its normal timeout
and not an installation-time benchmark. Its network errors are retained.

The record contains one complete successful driver run, including expected
negative operations. Earlier harness corrections are not candidate failures.
In particular, the executable must be mounted with basename `mise`, not renamed
to a different executable name that mise interprets as a tool shim.

## Reproduce the online preparation

Prerequisites are Docker, Python 3, the pinned mise/aqua binaries from the previous
experiments, the M3 Ubuntu image `score-mise-m3:local-amd64`, and a Nix producer
containing the recorded M4 starpls derivation. The Linux image identity is in
`preparation.json`; this is a bounded comparison, not a general host bootstrapper.
Use a fresh workspace for each complete run and a fresh Nix target store.

From the repository root, set these paths for your disposable environment:

```bash
export SCORE_OPS_WORK=/tmp/score-operations-reproduction
export SCORE_OPS_MISE=/tmp/score-m4-mise/bootstrap-check/mise
export SCORE_OPS_AQUA=/tmp/score-aqua-eval/bootstrap/aqua
```

The following prepares both mise lock variants, aqua and the existing installer.
The first mise lock is the accepted published lock copied as fixture input. The
second is **generated by mise**, with metadata-only checksum lookup disabled.
Both select the same starpls version and archive bytes.

```python
# Run with python3 from the repository root, after setting the variables above.
import json
import os
import shutil
import subprocess
from pathlib import Path

work = Path(os.environ["SCORE_OPS_WORK"])
work.mkdir()  # Refuse to reuse an existing installation.
fixtures = Path("experiments/tool-manager-comparison/operations-evidence/fixtures").resolve()
mise = os.environ["SCORE_OPS_MISE"]
aqua = os.environ["SCORE_OPS_AQUA"]
for name in ("mise", "mise-revalidated"):
    folder = work / name
    folder.mkdir()
    (folder / "mise.toml").write_text('[tools]\n"github:withered-magic/starpls" = "0.1.22"\n')
    env = {**os.environ, **{
        f"MISE_{key}_DIR": str(folder / value)
        for key, value in {"CONFIG": "config", "SYSTEM_CONFIG": "system",
                           "CACHE": "cache", "DATA": "data", "STATE": "state"}.items()
    }, "MISE_TRUSTED_CONFIG_PATHS": str(folder), "MISE_YES": "1"}
    if name == "mise":
        shutil.copy2(fixtures / "mise.lock", folder / "mise.lock")
    else:
        env["MISE_USE_VERSIONS_HOST"] = "0"
        subprocess.run([mise, "-C", str(folder), "lock", "--platform", "linux-x64"], env=env, check=True)
    subprocess.run([mise, "--locked", "-C", str(folder), "install"], env=env, check=True)
folder = work / "aqua"
folder.mkdir()
for name in ("aqua.yaml", "aqua-checksums.json", "starpls-registry.yaml", "policy.yaml"):
    shutil.copy2(fixtures / name, folder / name)
subprocess.run([aqua, "install"], cwd=folder, env={**os.environ,
    "AQUA_ROOT_DIR": str(folder / "root"),
    "AQUA_POLICY_CONFIG": str(folder / "policy.yaml")}, check=True)
subprocess.run(["python3", "tools/internal/devcontainer/install.py", "install",
                "starpls", "--destination", str(work / "baseline/bin")], check=True)
(work / "nix").mkdir()
shutil.copy2(fixtures / "nix-package.json", work / "nix/package.json")
```

Export the Nix package and runtime closure from the separate producer. The store
path below is the recorded M4 derivation; rebuild the accepted Nix fixture first
if your producer no longer has it. An independently rebuilt package may have a
different store path; update the disposable `nix/package.json` to that package's
actual `store` and `executable` paths rather than pretending the old path exists.

```bash
docker exec score-eval-nix-m3-agent nix \
  --extra-experimental-features 'nix-command flakes' copy --offline \
  --to file:///tmp/score-operations-export \
  /nix/store/4piyxr19n8s6dck66xbjirfn7f9w3722-starpls-0.1.22
docker cp score-eval-nix-m3-agent:/tmp/score-operations-export "$SCORE_OPS_WORK/nix/cache"
docker run -d --name score-operations-nix --network none \
  --mount "type=bind,src=$SCORE_OPS_WORK/nix,dst=/probe" \
  --entrypoint sleep \
  nixos/nix@sha256:f159a58f390677f41e8e900a74b6e2f9c7f27b364122ae6acf7a652ce6c551c0 \
  infinity
```

The file cache is an **explicit prefetch/export**, not a default archive cache
claimed to exist for every manager. Its local unsigned fixture entries are
trusted only for this disposable probe.

## Run the isolated operations

```bash
python3 experiments/tool-manager-comparison/operations-probe.py \
  --workspace "$SCORE_OPS_WORK" \
  --mise "$SCORE_OPS_MISE" --aqua "$SCORE_OPS_AQUA" \
  --nix-container score-operations-nix
```

The driver writes `operations-results.json` in the workspace after every command
and validates corruption, repair and selection outcomes with assertions. Some
individual commands are expected to fail; the completed driver itself must exit
zero. Its Nix repair explicitly enables substitution from `file:///probe/cache`
because Nix disables substitution when networking is absent.

Afterwards remove only the disposable target container:

```bash
docker rm -f score-operations-nix
```

The producer may be stopped if it was started only for this experiment. The
workspace can be retained for inspection. No Docker prune, shared cache deletion,
repository pin update, push or publication is part of this procedure.
